# Chicken Trip 2

A fun endless road-crossing game built with Flutter. Guide your chicken across busy roads, collect coins, unlock skins, and beat your high score!

## Features

- Swipe and tap controls
- Multiple unlockable chicken skins
- Offline leaderboard
- Increasing difficulty
- Coin collection system

## Getting Started

```bash
flutter pub get
flutter run
```

## Build for Release

```bash
flutter build appbundle --release
```
